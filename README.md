# My Portfolio

Personal portfolio website for Christian — a Computer Engineering student and aspiring developer. Built with plain HTML, CSS, and JavaScript.

🔗 **Live repo:** https://github.com/Chan242-meant/my-portfolio

## Pages

| Page | Description |
|---|---|
| `index.html` | Home page |
| `about.html` | Background, skills, and bio |
| `projects.html` | Showcase of projects |
| `gallery.html` | Image gallery |
| `contact.html` | Contact information / form |

## Structure

```
my-portfolio/
├── index.html
├── about.html
├── projects.html
├── gallery.html
├── contact.html
├── formall.png
├── css/
│   └── style.css
└── js/
    └── main.js
```

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Getting Started

Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/Chan242-meant/my-portfolio.git
cd my-portfolio
open index.html
```

No build tools or dependencies required.
